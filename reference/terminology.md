# Terminology

Always use the term that real coaching / exercise-science literature uses in the
language you are writing. Never a literal word-for-word translation (a "calque") and
never invented jargon — if you are unsure of a language's established term, describe the
concept in plain words rather than transliterating the English one.

Keep these acronyms verbatim in every language: TSS, FTP, IF, NP, VO2max, W′, CTL, ATL,
TSB, HRV, RPE.

Each section below maps an English source term → the term to use in that language. Only
terms that are easy to get wrong are listed; obvious cognates need no entry. To support
another language, add a new `## <Language> (<code>)` section in the same `english → local`
arrow format — nothing else needs to change.

## Swedish (sv)

- workout / training session → pass
- power → effekt
- power curve → effektkurva
- threshold → tröskel
- endurance / durability → uthållighet
- recovery → återhämtning
- cadence → kadens
- intervals → intervaller
- hill intervals → backintervaller
- base / build / peak / taper → bas / uppbyggnad / toppning / nedtrappning
- gut training (carb tolerance / fuelling, e.g. mot 90 g/h) → träna magen  — never "tarmträning" (a calque no Swedish coach uses)
