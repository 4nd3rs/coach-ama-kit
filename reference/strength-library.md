# Strength session library

Named, reusable strength sessions. The coach ASSIGNS these per athlete and
repeats them week to week — the calendar name is the identity that makes reuse
visible. Dosing/periodization authority stays in the coaching reference (§7
for cycling); this file holds the sessions themselves, their equipment
variants, and the rules that keep them identical across weeks. A different
strength session every week is worse coaching AND worse science than the same
one progressing.

## 1. Why the plan repeats (the athlete may ask — answer with this)

- Rotating exercises gives NO strength or hypertrophy advantage over a fixed
  program (Baz-Valle 2019 RCT; 2022 systematic review) — 1RM gain is partly
  skill-specific, so novelty actively dilutes it.
- Progressing by feel at a target RIR (reps in reserve) beats fixed-percentage
  loading (Graham & Cleather 2021; 2022 autoregulation meta-analysis).
- Therefore: the SAME named session repeats in 6–8-week blocks; exactly ONE
  variable progresses per week; exercises change only at phase transitions,
  equipment change, injury/pain, or athlete request — and the why goes in PLAN.

## 2. The named sessions

Two session identities, A and B. Translate their display names into the
athlete's coaching language, then keep those localized names stable. Swedish
examples below are templates, not mandatory calendar titles. For Ukrainian:
`Силове тренування A — Сила ніг` and
`Силове тренування B — Стійкість тіла`. Translate description headings too:
never leave `STYRKA A/B` inside an otherwise localized prescription.

Language correction is an exception to byte-stable copy-forward: if an assigned
name was saved in the wrong language, correct the name in PLAN and future
AMA-owned calendar entries in place, record the language-only reason in PLAN,
and reuse the corrected name thereafter. Preserve A/B identity, exercises,
sets/reps, duration, load and dates. Do not rewrite historical workouts or
external providers' entries to make their language match.

- **`Styrka A — Tunga ben`** (EN: `Strength A — Heavy legs`) — the
  economy/max-strength session. Three equipment variants below; assign ONE.
- **`Styrka B — Robusthet`** (EN: `Strength B — Robustness`) — crash-resilience,
  trunk, neck (reference robustness dose). The PLAN assignment decides its
  shape: its own weekly workout, or folded into A as its B-block
  (`Styrka A (gym, inkl. B-block)`). Whichever shape is assigned stays stable
  week to week.

## 3. Styrka A — three equipment variants

Assign by USER "Strength equipment". Sets/reps below are the Max-Strength
block; the §5 overlay adjusts for AA and Maintenance.

### Gym (~50 min) — the validated protocol
| # | Exercise | Prescription |
|---|----------|--------------|
| 1 | Half-squat (leg press if no rack) | 4×5 @ 4–6RM (1–2 RIR), 2–3 min rest, maximal intended concentric speed |
| 2 | Single-leg leg press (or Bulgarian split squat) | 3×6/leg @ 6RM, 2 min |
| 3 | Standing calf raise | 3×8 @ 8RM, 90 s |
| (4) | One-legged hip flexion, cable/band (optional) | 2×10/leg |

### Home weights (~40 min) — dumbbells/kettlebells up to ~2×24 kg
| # | Exercise | Prescription |
|---|----------|--------------|
| 1 | Rear-foot-elevated split squat, both bells | 4×5–8/leg @ 1–2 RIR, 2–3 min |
| 2 | Single-leg RDL (bell in opposite hand) | 3×6–8/leg @ 2 RIR, 2 min |
| 3 | Heavy step-up, knee-height box, both bells | 3×6/leg @ 2 RIR, 2 min |
| 4 | Single-leg calf raise, bell in hand | 3×8–10/leg @ 1–2 RIR, 90 s |

The rear-foot-elevated split squat drives strength gains equal to the back
squat (Speirs 2016) with hip-extensor moments at least as large (Mackey &
Riemann 2022); with both bells, one-leg work sits genuinely in the 5–8RM zone
for most riders. **Load-ceiling ladder** — when the heaviest bells stop being
1–2 RIR, progress ONE step at a time, in order: double progression (4×5 →
4×8) → add a 5th set → 3 s eccentric → 2 s bottom pause → deficit (front foot
on ~5 cm plate) → 1½-reps → final set to 0–1 RIR.

### Bodyweight (~35 min) — honest best-available
| # | Exercise | Prescription |
|---|----------|--------------|
| 1 | Jump work FIRST, fresh: squat/split-squat jumps → single-leg hops/bounds | 3×5–8, max intent, 2 min full rest |
| 2 | Hardest owned single-leg squat step (step-down → assisted pistol → box pistol → full pistol; shrimp = knee-flexion alternative) | 4×4–8/leg @ 1–2 RIR, 2–3 min |
| 3 | Nordic curl, eccentric-only (feet anchored under sofa/partner) | 3×3–5 building to 3×8–12 over ~4 wk |
| 4 | Split-squat iso hold (long muscle length) + slow single-leg calf raises | 30–45 s/leg + 3×12–15 (0–1 RIR calves) |

Explosive jump work is the strongest bodyweight card for cyclists (Paton &
Hopkins 2005: +8 % 1-km power, ~3 % lower O₂ cost in competitive cyclists);
Nordics build eccentric hamstring strength at tiny volumes (Mjølsnes 2004).
Be honest with the athlete: this tier maintains and builds meaningfully but
cannot fully replicate the heavy-load stimulus — when they get access to two
heavy dumbbells or a gym, suggest moving up a tier.

## 4. Styrka B — robustness by tier

Same movement intents as the reference robustness menu, mapped per tier.
2–3 sets × 8–15RM (or as noted), controlled, 60–90 s rest, ~10–15 min total.
Pick 4–6 and KEEP them — same rotation-resistance as everything else.

| Intent | Gym / home weights | Bodyweight |
|---|---|---|
| Press | DB overhead/floor press 3×8 | Push-up ladder (incline → standard → decline → archer) 3×AMRAP−2 |
| Pull | Bent-over DB row 3×8–10/side | Inverted row under a sturdy table, or towel row round a door 3×8–12 |
| Scapular control | DB prone Y-T raises 2×10 | Scap push-ups + wall slides 2×12 |
| Neck | 4-way isometrics vs own hand 3×10 s each direction | same |
| Trunk anti-rotation | Suitcase carry 3×30 m / renegade row | Side plank 3×30–45 s/side + bird-dog |
| Grip | Farmer hold 3×30–45 s | Towel hang or ledge hold |

## 5. Phase overlay — same exercises, different dose

| Phase | Dose change (Styrka A) |
|---|---|
| Anatomical Adaptation (2–3 wk, off-season start / strength-novice ramp) | 2–3 sets × 8–12RM, technique + tendon prep |
| Max Strength (base/pre-build, ≥8–12 wk, 2×/wk) | as written in §3: 3–4 sets, 4–8 reps @ 1–2 RIR |
| Maintenance (build/peak/in-season, 1×/wk) | SAME loads, drop to 2–3 sets; never in the 48 h before a key session; no heavy legs the final 10–14 days before an A-race |

A phase transition changes THIS TABLE's row, not the exercise list, and gets
one line in PLAN (what changed, from when).

## 6. Consistency rules — how the same session stays the same

- **Copy-forward:** when writing this week's instance, `read_planned` over the
  PAST week, open last week's entry, and reproduce its description with only
  the progression-relevant numbers changed. If the athlete says "same as last
  time": byte-identical except the load/progression line.
- **One variable per week**, chosen by RIR: all reps clean at target RIR → add
  load (or take the next ladder step). Stalled two weeks → deload ~10 % for one
  week, resume; still stalled → step the ladder, never the exercise list.
- Before writing strength, read the last ~14 days of the calendar — if the
  strength session you are about to write does not match the assigned name
  there, stop: you are probably inventing. A deliberate rename needs its reason
  recorded in PLAN.

## 7. Assigning sessions + equipment discovery

- Assignment lives in PLAN → `## Strength`: session names + variant + weekday
  slots + current phase (+ athlete-reported loads when known).
- Equipment lives in USER → "Strength equipment". If unknown, ask ONE question
  at the next natural strength touchpoint ("Har du tillgång till gym, hantlar
  hemma, eller kör vi utan utrustning?"), write the answer to USER, and never
  re-ask. Until known, default to what their current sessions imply.
- Adaptation stays coaching judgment: time-crunched week → cut sets, keep the
  session and its name; injury/pain → swap ONLY the affected movement and note
  it in PLAN.

## 8. Writing the session — the description template

Every strength description follows this skeleton, in the athlete's language
(shown in Swedish — mirror the structure exactly in other languages). Concrete
lifts, real numbers, no internal jargon in athlete text (never "RFD",
"type II", "non-osteogenic", "interference").

```
STYRKA A — TUNGA BEN · gym · ca 50 min
Syfte: <one line>. Samma pass varje vecka — vikten ökar, övningarna byts inte.

Uppvärmning (8 min): <one line: easy cardio + mobility + ramp-up sets>

A — Tunga ben
1. <Övning> — <set>×<reps> @ <RM/RIR>, vila <t>, <intent>
2. …

B — Robusthet (10 min)   ← only when B rides inside A
4. …

Progression: <the ONE variable that moves next time>
Placering: <interference rule in plain language, e.g. "efter dagens pass eller
på en lätt dag; aldrig tunga ben 48 h före lopp eller nyckelpass">
```

A strength day with no sets/reps/rest is under-prescribed; a strength day that
does not match the athlete's assigned library session is a drift bug unless
PLAN records why.
